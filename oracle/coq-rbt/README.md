# Trusted RBT oracle (hand-written 2023 Coq)

This is a **deterministic oracle** for the red-black-tree workload, built from the
**hand-written** Coq implementation in the original ETNA artifact
([`jwshii/etna` `workloads/Coq/RBT`](https://github.com/jwshii/etna)) — preferred
over the recent AI-assisted ports because it is the authors' own code.

It runs the authors' `Impl.v` (algorithms: `balance`, `insert`, `balLeft/Right`,
`_join`, `del*`, `delete`) and `Spec.v` (predicates `isRBT`/`toList`/`L_insert`
and the 10 properties) **verbatim**, evaluating each `etna.toml` witness with
`Compute` to a definite `Some true` / `Some false` / `None`. No randomized
QuickChick `Checker` is run — the properties are `option bool`, so they reduce
deterministically on concrete inputs.

## Provenance & the only modifications

- `Impl.v`, `Spec.v` — copied from `jwshii/etna` `workloads/Coq/RBT/Src/`. The
  **algorithms and properties are unchanged**. The only edits, all non-semantic:
  - `Axiom fuel` → `Definition fuel := 1000%nat.` (an axiom can't be reduced by
    `Compute`; 1000 ≫ the depth these tiny witness trees need, so the result is
    identical to the authors' extraction-time `100000`).
  - Removed `Derive (Arbitrary, Show) …` lines (random-generator / Show
    scaffolding for the *fuzzer*; unused when computing on concrete inputs).
  - Added `From RBT Require Import QcEtna.` to `Spec.v`.
- `QcEtna.v` — the `-=>` (`Implies`) and `==?` (`PolymorphicEquality`) operators
  the workload uses, **copied verbatim** from the ETNA *fork* of QuickChick
  (`src/Decidability.v`). Released `coq-quickchick` omits these (they're fork
  additions); the fork itself won't build on the current dune/OCaml toolchain, so
  we supply just these two operator definitions. The property *logic* is the
  authors'.
- `Oracle.v` — generated by `gen_oracle.py` from the RBT `etna.toml` witnesses:
  one `Compute ("mut/prop"%string, prop_X <coq term>)` per witness.

## Run

```bash
./run.sh        # prints: = ("delete_4/DeleteDelete"%string, Some true)  ...
```

Current result: **all 38 witnesses → `Some true`** on the clean implementation.

## Regenerate Oracle.v (e.g. for new inputs)

`python3 gen_oracle.py > body.v` then prepend the `Oracle.v` header (see the
file). The translator reads witnesses from a checkout of `etna-rust-rbt`'s
`etna.toml`; point it at whatever input set you want the oracle to rule on.
